MASKLESS LITHO v2.0.9

MASKLESS LITHO v2.0.9는 DLP 기반 마스크리스 리소그래피 장비를 제어하는 Windows 데스크톱 소프트웨어입니다. 이미지 또는 GDS layout을 DLP 출력용 패턴으로 준비하고, Align View와 Draw CAD를 이용해 현미경/카메라 화면 기준으로 패턴을 정렬하거나 직접 CAD 도형을 추가할 수 있습니다.

Build: maskless_v2_0_9.exe Single EXE Focus Mode Load GDS Motorized Focus UV Keystone Calibration Draw CAD

bolt 2. Quick Start

장비를 처음 사용하는 사용자를 위한 빠른 시작 가이드입니다.

  • 장비 전원 확인 및 PC 연결
  • 소프트웨어 실행 및 초기화
  • 패턴 로드 및 노광 설정
  1. Initialize: 상단 메뉴의 Initialize 버튼을 눌러 스테이지와 광원을 초기화합니다.
  2. Load Pattern: Load Image 또는 Load GDS를 통해 노광할 패턴을 불러옵니다.
  3. Focus: Motorized Focus를 이용해 시편의 초점을 맞춥니다.
  4. Expose: Start 버튼을 눌러 노광을 시작합니다.

health_and_safety 3. Safety

장비 사용 시 다음 안전 수칙을 반드시 준수하십시오.

  • UV 광원을 직접 눈으로 보지 마십시오.
  • 장비 가동 중 스테이지에 손을 대지 마십시오.
  • 비상 정지 버튼의 위치를 숙지하십시오.

install_desktop 4. Install/Run

소프트웨어 설치 및 실행 방법입니다.

1

제공된 USB 또는 다운로드 링크에서 maskless_v2_0_9.exe 파일을 실행합니다.

2

필요한 드라이버(DLP, Camera, Stage)가 설치되어 있는지 확인합니다.
